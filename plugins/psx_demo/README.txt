PSX Framework Demo
==================

Run psx_demo.exe. The game keeps its data in psx_demo_data beside it; the whole
folder can be copied anywhere.

  WASD / arrows   move and turn (tank controls)
  H               hide the key list
  N               next level           R   recentre the drag camera
  V               vertex snapping      T   affine / perspective textures
  G               subdivision          L   lighting
  B               dim ambient          O   overbright
  C               15 / 24-bit colour   X   dithering
  F               draw distance + fog  K   colour key
  M               player blend mode    P   CRT effects
  Y               CRT overscan         I   interlaced video mode
  U               interlacing          TAB widescreen
  F11             fullscreen           F12 screenshot (psx_screenshot.png)

Options: --psx-shot=<file.png> [--psx-shot-frames=<n>] saves a screenshot after
n frames and quits.
